# Robotic Manipulator Kinematic Modeling and Simulation

## Project Overview
This repository provides an object-oriented MATLAB framework for the kinematic modeling and simulation of a 7-DOF robotic manipulator (comprising 6 rotational joints and 1 prismatic joint). The project implements foundational robotics algorithms from scratch, including Direct Kinematics (Forward Geometry), Jacobian matrix computation, and 3D trajectory visualization.

## Mathematical Architecture

### Forward Kinematics (Direct Geometry)
The spatial configuration of the manipulator is computed using homogeneous transformation matrices. For a given joint configuration vector $q \in \mathbb{R}^7$, the pose of any frame $k$ with respect to the base frame is calculated via successive matrix multiplications:
$$^0T_k(q) = \prod_{j=1}^{k} {^{j-1}T_j(q_j)}$$
Where $^{j-1}T_j(q_j)$ represents the local transformation incorporating both the fixed geometric offset and the variable joint motion (rotational or prismatic).

### Differential Kinematics (Jacobian Matrix)
The system analytically computes the geometric Jacobian matrix $J \in \mathbb{R}^{6 \times 7}$, mapping joint velocities $\dot{q}$ to the operational space twist (linear and angular velocities) of the end-effector or any intermediate link:
$$\begin{bmatrix} v \\ \omega \end{bmatrix} = J(q) \dot{q}$$
The Jacobian columns are computed dynamically based on the joint type (revolute or prismatic) utilizing cross products and rotation axes extracted from the direct geometry transformations.

## Software Architecture
The framework is built using a modular, object-oriented approach in MATLAB:
- **`BuildTree.m`**: Initializes the kinematic chain and fixed transformations.
- **`geometricModel.m`**: Class responsible for updating direct geometry and computing base-to-frame transformations.
- **`kinematicModel.m`**: Class responsible for deriving the Jacobian matrix for any specified link.
- **`plotManipulators.m`**: Class handling the 3D rendering and motion animation of the manipulator.
- **`main.m`**: The main execution script running the simulation loop and testing specific configurations and twist projections.

## How to Run

**Prerequisites:**
- MATLAB (No specific toolboxes required; relies on core matrix operations)

**Execution:**
1. Clone the repository.
2. Ensure the `include` folder (containing the class definitions) is in the same directory as `main.m` or added to the MATLAB path.
3. Run `main.m` to execute the kinematic computations and launch the 3D simulation of the manipulator.
