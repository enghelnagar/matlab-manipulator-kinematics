# Robotic Manipulator Kinematic Modeling and Simulation

## Project Overview
This repository provides an object-oriented MATLAB framework for the kinematic modeling and simulation of a 7-DOF robotic manipulator (comprising 6 revolute joints and 1 prismatic joint). The project implements foundational robotics algorithms from scratch, including Forward Kinematics ($SE(3)$ transformations), geometric Jacobian computation, twist projections, and 3D trajectory visualization.

## Mathematical Formulation

### 1. Direct Kinematics (Forward Geometry)
The spatial configuration of the manipulator is computed using homogeneous transformation matrices belonging to the Special Euclidean group $SE(3)$. For a given joint configuration vector $q \in \mathbb{R}^7$, the pose of any frame $k$ with respect to the base frame (frame 0) is calculated via successive matrix multiplications of the local transformations:

$$^0T_k(q) = \prod_{j=1}^{k} {^{j-1}T_j(q_j)}$$

Where $^{j-1}T_j(q_j)$ represents the local transformation incorporating both the fixed geometric offset and the variable joint motion (rotational or prismatic). The end-effector pose is extracted from $^0T_7(q)$.

### 2. Differential Kinematics (Geometric Jacobian)
The system analytically computes the geometric Jacobian matrix $J(q) \in \mathbb{R}^{6 \times 7}$, which establishes the linear mapping between the joint space velocities $\dot{q}$ and the operational space twist (linear velocity $v$ and angular velocity $\omega$) of the end-effector relative to the base frame:

$$\begin{bmatrix} v \\ \omega \end{bmatrix} = J(q) \dot{q}$$

The Jacobian is constructed column by column. Let $z_{i-1}$ be the axis of actuation for joint $i$, and $p_{i-1}$ be its position vector, while $p_e$ is the position of the end-effector. The $i$-th column of the Jacobian, $J_i$, is formulated based on the joint type:

**For a Revolute Joint ($Type = 0$):**

$$J_i = \begin{bmatrix} z_{i-1} \times (p_e - p_{i-1}) \\ z_{i-1} \end{bmatrix}$$

**For a Prismatic Joint ($Type = 1$):**

$$J_i = \begin{bmatrix} z_{i-1} \\ 0_{3 \times 1} \end{bmatrix}$$

### 3. Twist Projection (Frame Transformation)
The framework also computes the projection of the operational space twist from the base frame to the local end-effector frame. Given the rotation matrix from the base to the end-effector $R_e^0$, the projected linear velocity $v^e$ and angular velocity $\omega^e$ are computed as:

$$v^e = (R_e^0)^T v^0$$

$$\omega^e = (R_e^0)^T \omega^0$$

## Software Architecture
The framework is built using a modular, object-oriented approach in MATLAB to ensure scalability and strict adherence to robotic software design principles:
- **`BuildTree.m`**: Initializes the kinematic chain, defining the fixed transformation matrices $^iT_{i+1}(0)$.
- **`geometricModel.m`**: Core class responsible for updating the direct geometry, applying $Z$-axis rotations for revolute joints and $Z$-axis translations for prismatic joints.
- **`kinematicModel.m`**: Class responsible for dynamically deriving the Jacobian matrix for any specified link using cross-product methodologies.
- **`plotManipulators.m`**: Class handling the 3D rendering, plotting the base-to-joint vectors, and animating the manipulator's motion.
- **`main.m`**: The primary execution script that runs the simulation loop, evaluates custom configurations, and computes projected twists.

## How to Run

**Prerequisites:**
- MATLAB (No additional toolboxes are strictly required; the framework relies on core matrix algebraic operations).

**Execution:**
1. Clone the repository.
2. Ensure the `include` folder (containing the OOP class definitions) is in the same directory as `main.m` or explicitly added to the MATLAB path.
3. Run `main.m` to execute the kinematic computations, validate the Jacobian matrices, and launch the 3D simulation of the manipulator.
